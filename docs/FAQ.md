# 常见问题（FAQ）

## 1. 为什么杀毒软件 / Windows Defender 报毒？

本软件用 **PyInstaller** 打包为单文件 exe，这类打包程序常被误报。所有源码均开源，可自行审计或重新打包。如果被拦截，请：

- 在杀毒软件中添加信任 / 排除项；
- 或从源码自行打包（见 README「从源码运行」）。

## 2. 我的 API Key 安全吗？

- API Key 只保存在本地 `~/.model_balance/accounts.json`，**Windows 下用系统 DPAPI 加密**（绑定当前用户，其他账户/其他机器无法解密）。
- 软件不会把 Key 上传到任何第三方服务器，所有请求只发往各服务商官方接口。
- 浏览器登录态也仅保存在本地 `~/.model_balance/browser_profile`。

## 3. 余额 / 消费金额和官网对不上？

- 软件显示的是**同步时刻的快照**，官网是**实时数据**，两者存在时间差（几分钟内的新增调用会导致差异）。
- 部分平台余额走 HTTP 接口、消费走浏览器同步，口径可能不同。
- 一切以服务商网页账单为准。

## 4. 为什么有些平台必须「同步官方」才能看到余额？

- 只有**无公开 HTTP 余额接口**的平台（如智谱）才必须走浏览器同步。
- 其余平台（DeepSeek / Kimi / 硅基流动 / OpenRouter）填 API Key 即可通过 HTTP 查询余额。

## 5. 浏览器同步很慢 / 失败？

- 同步需要启动内置浏览器并打开平台控制台，通常几秒到几十秒。
- 常见原因：网络无法访问该平台、尚未在软件浏览器登录、平台登录态过期。在「同步官方」弹出的窗口重新登录一次即可。

## 6. 数据存在哪里？如何备份？

所有数据在用户目录 `~/.model_balance/`：

- `accounts.json`：账号（API Key 加密）
- `settings.json`：设置
- `browser_profile/`：浏览器登录态
- `daily_cache.json` / `*_cache.json`：每日用量与同步缓存
- `app.log`：运行日志

备份整个 `~/.model_balance/` 目录即可（换电脑后把 API Key 重新输入也可）。

## 7. 如何彻底卸载？

- 删除下载的安装包；
- 删除数据目录 `~/.model_balance/`（备份过的可保留）。
- 软件不写注册表 / 开机自启项，删除即完。

## 8. 每日用量 / 每小时分布没有数据？

- 平台能力限制：DeepSeek / OpenRouter 有 Token 与每小时分布；Kimi / 智谱 / 硅基流动只有每日金额、无每小时 Token 分布。
- 部分平台日账单次日更新，当天可能显示为空。
- 已同步过的数据会缓存，离线也能看历史；未同步时打开每日用量会触发后台同步。

## 9. 通用中转站查不到余额？

软件会依次尝试多个常见余额接口路径（OpenAI 计费格式、new-api / one-api 的 quota 格式、通用 balance 字段）。如果仍查不到，可能是该中转站余额接口路径不同，可在 Issue 中提供其接口地址，便于接入。

## 10. 重启软件后账号还在吗？

在。账号、设置、主账号、排序等都保存在本地 `~/.model_balance/`，重启自动恢复。

## 11. 开机打开软件为什么还要等很久？

首次打开会自动刷新余额（HTTP，快）并后台同步官方（浏览器，较慢）。余额很快显示；消费 / 每日用量等官方数据同步完成后自动补上。
